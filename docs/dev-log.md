## 一、最终形态

单页 H5 互动随笔集：**封面（轻触开启）→ 选择页（随笔集）→ 随笔正文（自动配乐）**，可直接分享到微信/抖音。

- 技术：原生 HTML/CSS/JS + **GSAP** + **Three.js**（均本地打包，不走 CDN，零外部依赖）
- 字体：霞鹜文楷（OFL 可商用），按全站用字子集化为 2 个 woff2（约 195KB/194KB）
- 部署：GitHub Pages + Cloudflare Pages 双端镜像；资源自动版本号防微信缓存

## 二、功能清单

| 模块 | 说明 |
|---|---|
| 封面 | 金色粒子流 + 5 颗呼吸五角星（均匀分布、不越界标题区、点击收缩-回弹 + 迸发光粒）+ 每 2.3s 流星；整层与文字同步淡入；仅"轻触 开启"进入 |
| 选择页 | 三篇随笔卡片（内部滑动 + 下滑提示）、柔光返回/进入箭头、左上角返回封面 |
| 随笔正文 | 流动式段落（滚动渐入）、金色标题、插图（圆角/投影/随滚动渐入）、歌词插页、落款；左上角返回选择页换读 |
| 音乐 | 每篇独立配乐（`<audio>`，进入即响），右上三根音柱随播放跳动；底部歌词"彩蛋"——仅手动开关音乐后轮播 |
| **彩蛋** | 封面 5 颗星从左到右依次点击 **2、2、4** → 进入 3D 亚克力相册页：**前面照片清晰、背面模糊镜像**、通透亚克力边框（移植自 `gsap-acrylic-polaroid`）、鼠标/手指拖拽旋转；右侧文案"**相逢已是上上签**"；背景透出站点粒子 |
| 沉浸 | 全局粒子（星尘 + 柔光晕）、阅读进度条、移动端优先、`prefers-reduced-motion` 适配 |

## 四、工程要点

- **配置驱动**：换文/换歌/换主题/插图只需改 `js/essays.js`（每篇一个对象，可含 `image`），不动引擎。
- **字体子集化**：`scripts/build-fonts.js`（基于 `subset-font`，源 TTF 在 `assets/fonts/_source`，换文后重跑）。
- **一键发布**：`deploy.bat` 双击完成——自动更新 `?v=` 资源版本号（防缓存）→ `git push`（需本机代理 7897）。
- **缓存策略**：css/js 引用带 `?v=` 随机串，每次发布更换，微信等不再缓存旧版。
- **彩蛋引擎**：`js/egg3d.js`（Three.js 相册）+ `js/app.js` 内序列检测与页面控制。

## 五、已知限制

1. 音乐为商业版权歌曲，公网分享请自行确认合规。
2. 抖音私信默认拦截外链：先浏览器打开，再"复制链接"发送。
3. iOS 静音键开启时 `<audio>` 可能无声（平台限制）。
4. 歌词未配时间轴，走轮播；可在 `essays.js` 为 `lyrics` 补 `time`（秒）精确同步。
