# 开发日志 · 最终版

> 项目：互动随笔网页《杂文随笔》
> 完成：2026-08-01
> 目录：`interactive-essay/` · 站点：https://providence120.github.io/essay/

---

## 一、最终形态

单页 H5：**封面（缓冲/开启）→ 音乐响起 → 随笔流动展开**，可直接分享链接到微信/抖音聊天。

- 技术：原生 HTML/CSS/JS，**零依赖、零外部插件**
- 字体：霞鹜文楷（OFL 开源可商用），按本篇随笔子集化为 2 个 woff2（约 255KB）
- 托管：GitHub Pages，资源带自动版本号，微信不缓存旧版

## 二、最终功能

| 模块 | 效果 |
|---|---|
| 封面 | 金色粒子流 + **5 颗呼吸五角星**（均匀分布、不越界标题区、点击收缩-回弹并迸发金色光粒）+ 每 2.3 秒一道流星；整层与文字同步淡入；**仅"轻触 开启"按钮进入** |
| 音乐 | 王极《again》内置；右上角三根音柱随播放跳动（可关闭）；歌词轮播显示 |
| 随笔 | 流动式段落（滚动渐入、两格间距）、金色标题、歌词插页、落款 |
| 沉浸 | 全局粒子（星尘 + 柔光晕）、阅读进度条、移动端优先、`prefers-reduced-motion` 适配 |
| 多篇 | `js/essays.js` 每篇一个对象，`?id=篇id` 独立链接互不覆盖；多篇时自动显示目录页 |

## 三、工程要点

- **配置驱动**：换文 / 换歌 / 换主题只需改 `js/essays.js`，不动引擎。
- **字体子集化**：`scripts/build-fonts.js`（基于 `subset-font`），换文后重跑即可。
- **一键发布**：`deploy.bat` 双击完成——自动更新资源版本号（防缓存）→ `git add/commit/push`。
- **缓存策略**：css/js 引用带 `?v=` 随机版本号，每次发布自动更换，微信等浏览器不再卡旧版。

## 四、使用

```bash
# 本地预览
cd interactive-essay && npx http-server -c-1 -p 8080

# 发布（需本机代理 127.0.0.1:7897 开启）
双击 deploy.bat
```

每篇随笔分享地址：`https://providence120.github.io/essay/?id=篇id`（第一篇 `?id=shoubi`）。

## 五、已知限制

1. 音乐为商业版权歌曲，公网分享请自行确认合规。
2. 抖音私信默认拦截外链：先在浏览器打开，再"复制链接"发送。
3. iOS 静音键开启时 `<audio>` 可能无声（平台限制）。
4. 歌词未配时间轴，当前按节奏轮播；可在 `essays.js` 中为 `lyrics` 补 `time`（秒）实现精确同步。
